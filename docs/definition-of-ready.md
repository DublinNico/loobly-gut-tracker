# Definition of Ready

A story can move from **Backlog** to **Ready** (and into a sprint) only when:

- [ ] It has a requirement ID from the SRS (e.g. `FR-04`)
- [ ] It's written as "As a… I want… so that…"
- [ ] Acceptance criteria are written as Given/When/Then and are testable
- [ ] It has a MoSCoW label and a size (XS–XL)
- [ ] It's small enough to finish in one sprint (split it if it's XL)
- [ ] Dependencies are done or in the same sprint
- [ ] The wireframe artboard is linked (if it has UI)
- [ ] Test ideas are noted (edge cases, boundary values, risks)
