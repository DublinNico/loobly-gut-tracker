# 0003. Expo managed workflow with TypeScript

- **Status:** Accepted
- **Date:** 2026-11-22

## Context

Solo developer, Android first, learning React Native, wants fast iteration on a real phone and cloud builds without a Mac or a local Android build setup.

## Decision

Use Expo (managed workflow) with TypeScript and Expo Router. Build and sign with EAS Build. Don't commit `android/`/`ios/` — they're generated by prebuild.

## Options considered

| Option | Pros | Cons |
|---|---|---|
| Expo managed | Expo Go on phone, EAS builds, OTA updates, good docs | Some native modules need a dev build |
| Bare React Native | Full native control | Gradle/Xcode setup, slower to learn |
| Flutter / native Kotlin | Performance, native feel | New language; less reuse of React/JS skills |

## Consequences

- SQLCipher and some modules need a development build instead of Expo Go.
- Upgrade dependencies with `npx expo install --fix`, not blind npm updates.
